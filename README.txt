PALAK BIRTHDAY WEBSITE ❤️

This is a complete static website and can be hosted free with GitHub Pages.

IMPORTANT:
Upload the contents of this folder to a GitHub repository. Do NOT upload the ZIP itself.

GitHub Pages:
1. Create a new public GitHub repository.
2. Upload index.html, all other HTML/CSS/JS files, and the photos folder.
3. Open Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root).
6. Save and wait for the published link.

The main page is index.html.
Keep the photos folder beside the HTML files so all photos load correctly.

Tip:
Test index.html locally first. For the final surprise, send only the published website link to Palak.
